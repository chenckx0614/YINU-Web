# 一隅网页版

网页版可以在浏览器本机记录，也可以用和手机相同的账号进入云端时间线。登录前的本机记录和账号记录各自保存，需要迁移时使用「设置 → 备份与恢复」。

## 网页功能

- 记录文字、链接、图片、文件和语音。支持文件选择、拖放和粘贴，网页新增的附件保存在浏览器，登录时排队上传至私有存储。
- 按正文、文件名、日期、类型和收藏分组筛选，支持引用、双向查找关联、设备内置顶、分享和查看记录详情。
- 支持多选、拖动连续选择、合并、长图导出、批量删除、撤销和本机最近删除恢复。
- 支持图片翻页、放大、旋转及标注，音视频播放、PDF 打开、DOCX 正文和纯文本文档预览，以及原件下载。
- 支持兼容 Android v1/v2 的 ZIP 备份恢复、缺失原件补回、深色模式和记录提醒。网页提醒依赖标签页和系统通知权限。
- AI 整理和语音转写使用用户配置的 OpenAI 兼容 API。服务需要允许浏览器跨域请求，密钥仅保存在当前标签页的内存。
- 在支持的浏览器中可安装为网页应用。完成一次联网加载后可离线打开，并可通过浏览器支持的快捷方式和分享入口接收内容。

## 连接真实记录

1. 创建 Supabase 项目，按 [同步设置](https://github.com/chenckx0614/YINU/blob/main/supabase/README.md) 运行 [初始化 SQL](https://github.com/chenckx0614/YINU/blob/main/supabase/yinu-sync.sql) 并启用邮箱登录。
2. 在手机「设置 → 跨设备同步」中登录。
3. 打开网页，点「连接我的记录」。默认项目直接使用同步邮箱和密码。自己部署时，展开「使用自定义项目」，填写手机端所用的项目地址和 Publishable 公钥，旧项目也可使用 anon 公钥。
4. 在任意一端新建一条文字记录。网页保持可见时约每 5 秒检查一次，也会在恢复联网或回到页面时同步。

网页首次打开时显示单独的示例记录。只有用自己的账号连接后，才会加载或上传真实数据。密码只用于登录，登录会话保存在当前浏览器标签页，未上传的修改按项目和账号暂存在浏览器中。

## 打开附件

在 Supabase 项目的 SQL Editor 运行一隅的 `supabase/yinu-attachments.sql`，然后在手机端 0.5.14 或更新版本的「设置 → 跨设备同步」点击「上传附件到云端」。回到网页版点击对应的附件卡片。常见图片和 Word 正文可以直接预览，PDF 可以在浏览器新标签页打开，所有已上传原文件都可下载。单个文件最多 50 MB，也受项目的存储容量限制。

## 本机启动

在仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`，浏览器打开 `http://127.0.0.1:8765`。网页为静态文件，也可以将 `dist` 发布到 HTTPS 静态站点。执行 `node --test *.test.mjs` 运行同步和备份测试。
