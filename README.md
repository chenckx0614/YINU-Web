# 一隅网页版

在电脑浏览器中使用和手机相同的记录。网页版读取正文、收藏、引用及附件信息，并能新增、编辑、收藏和删除记录。新增与修改会在联网后上传；手机和网页使用同一个冲突处理规则。

## 连接真实记录

1. 创建 Supabase 项目，按 [同步设置](https://github.com/chenckx0614/YINU/blob/main/supabase/README.md) 运行 [初始化 SQL](https://github.com/chenckx0614/YINU/blob/main/supabase/yinu-sync.sql) 并启用邮箱登录。
2. 在手机「设置 → 跨设备同步」中登录。
3. 打开网页，点「连接我的记录」。默认项目直接使用同步邮箱和密码。自己部署时，展开「使用自定义项目」，填写手机端所用的项目地址和 Publishable 公钥，旧项目也可使用 anon 公钥。
4. 在任意一端新建一条文字记录。网页保持可见时约每 5 秒检查一次，也会在恢复联网或回到页面时同步。

网页首次打开时显示单独的示例记录。只有用自己的账号连接后，才会加载或上传真实数据。密码只用于登录，登录会话保存在当前浏览器标签页，未上传的修改按项目和账号暂存在浏览器中。

## 打开附件

在 Supabase 项目的 SQL Editor 运行一隅的 `supabase/yinu-attachments.sql`，然后在手机端 0.5.14 或更新版本的「设置 → 跨设备同步」点击「上传附件到云端」。回到网页版点击对应的附件卡片。常见图片和 Word 正文可以直接预览，PDF 可以在浏览器新标签页打开，所有已上传原文件都可下载。单个文件最多 50 MB，也受项目的存储容量限制。

## 本机启动

在 `web` 目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`，浏览器打开 `http://127.0.0.1:8765`。网页为静态文件，也可以将 `dist` 发布到任意 HTTPS 静态站点。
